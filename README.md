# Созвон Квест

Не даёт забыть, что важно обсудить на созвоне. Перед звонком записываешь, что нужно спросить, сказать или о чём договориться. Во время разговора пункты отмечаются сами, как только ты их озвучил, и перед глазами всегда то, что ещё осталось. В конце балл из 100 и разбор: что узнал от собеседника, что упустил и в какой момент это было уместно поднять.

Созвон с клиентом, синк с командой, отчёт перед группой, собеседование: подходит любой звонок, где есть список того, что нельзя пропустить. Работает поверх Телемоста, Zoom, Meet и Teams. Открытый инструмент для Windows.

## Как пользоваться

1. Скачай `SozvonQuest-x.y.z-portable.exe` из [Releases](https://github.com/glxaoc/sozvon-quest/releases) и запусти. Установка не нужна. Windows при первом запуске покажет предупреждение SmartScreen «неизвестный издатель»: «Подробнее» → «Выполнить в любом случае». Подписи кода нет, это личный проект.
2. Мастер первого запуска предложит два режима:
   - **С ключом AiTunnel, рекомендуем.** Речь распознаётся на твоём компьютере, в облако уходит только текст для сверки. Работает на любом ноутбуке, час созвона стоит около 20 ₽. [AiTunnel](https://aitunnel.ru) — российский агрегатор нейросетей: оплата в рублях, без VPN. Ключ проверяется живым запросом и хранится только на твоём компьютере.
   - **Без ключа.** Всё работает на компьютере, ничего не уходит в интернет. Нужна видеокарта: после загрузки моделей (2,9 ГБ) мастер проверит скорость и честно скажет, потянет ли твой компьютер.
3. Выбери тип созвона и список пунктов: готовый, свой сохранённый или новый. Звёздочка в начале строки делает пункт критичным: вес двойной, а его пропуск режет ранг. Нажми «Начать созвон» и надень гарнитуру.

Что происходит дальше:

- **Типы созвонов.** Продажи, Команда, Отчёт, Другое. У каждого свои готовые списки, ранги и норма доли речи: на отчёте нормально говорить 80% времени, на продажах нет.
- **Закрытие пункта.** Когда ты его озвучил, карточка вспыхивает, летят частицы, появляется оценка PERFECT (сказано прямо) или GOOD (своими словами). Закрытия подряд дают серию ×2, ×3. Если ассистент не уверен, карточка помечается «PARTIAL?», и её можно закрыть кликом.
- **Компактный режим.** Кнопка с двумя полосками в шапке сжимает окно до одной строки со следующим пунктом, чтобы не закрывать созвон.
- **Степаныч в углу.** Корги-ассистент смотрит на того, кто говорит, прыгает при закрытии и дремлет, если все молчат. Тихо подсказывает, если ты говоришь дольше минуты подряд или пять минут ничего не закрывал.
- **Финал.** Балл из 100 докручивается с нуля, штампом влетает ранг. Ниже реплика Степаныча про этот созвон, что стоило спросить и в какой момент, что узнал от собеседника, доля речи и длиннейший монолог.
- **История.** Все созвоны лежат в Документы → SozvonQuest: `summary.md` для людей, `session.json` для машин.

**Важно.** Если в созвоне показываешь весь экран, собеседник увидит и эту панель, поэтому показывай окно или вкладку. И предупреждай собеседника, что ведёшь запись и разбор разговора.

## Как считается балл

| Блок | Вес | Что внутри |
|---|---|---|
| Покрытие пунктов | 65 | Perfect 1,0 · Good 0,8 · Partial 0,4 · Miss 0. Критичный пункт весит вдвое, его пропуск ставит потолок ранга A |
| Собранная информация | 25 | Для пунктов «узнать / спросить»: ответил ли собеседник по существу, уклончиво или не ответил |
| Тайминг | 10 | Доля пунктов, закрытых до последних 20 % созвона |

Доля речи, длиннейший монолог, слова-паразиты и частота смены говорящих показываются справочно, в балл не входят.

## Как устроено

```
renderer (Electron)                      main (Node)
┌───────────────────────┐   PCM16 16k   ┌────────────────────────────────────────────────┐
│ getUserMedia (микро)  ├──────────────►│ STT «me»  ──┐                                  │
│ getDisplayMedia       │   по IPC      │             ├─► transcript ─► ИИ-сверка ─► UI   │
│  audio:'loopback'     ├──────────────►│ STT «them» ─┘        │                         │
│ AudioWorklet → int16  │               │            финал: разбор + балл → summary.md   │
└───────────────────────┘               └────────────────────────────────────────────────┘
```

- **Два аудиоканала.** Микрофон через `getUserMedia`, системный звук через штатный Electron-механизм `audio: 'loopback'` (WASAPI). Поэтому работает с любым приложением для созвонов.
- **Распознавание на компьютере.** Модель [T-one](https://github.com/voicekit-team/T-one) от Т-Банка через [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx): стриминг, слова появляются по ходу речи, в 15–20 раз быстрее реального времени даже на одном ядре процессора. Есть облачные адаптеры: AiTunnel, Nexara, Yandex SpeechKit.
- **Сверка.** Через 0,4 с после каждой твоей реплики модель получает открытые пункты и окно твоей речи за 30 секунд. Отвечает JSON: какие пункты закрыты, цитата, уверенность. Порог автозакрытия 0,8. 17 регресс-кейсов в `test/test-llm.js`. В режиме без ключа сверку делает Qwen3.5-4B через [node-llama-cpp](https://github.com/withcatai/node-llama-cpp) на видеокарте (Vulkan).
- **Модели** скачиваются один раз в `%APPDATA%/SozvonQuest/models` с зеркала в России, с докачкой после обрыва.
- **Финал.** Один запрос на весь транскрипт: тип каждого пункта, ответы собеседника, где был уместный момент для пропущенных, реплика Степаныча. Балл считается в `src/main/score.js`.
- **Защита от эха.** Без гарнитуры микрофон слышит динамики. Если твоя реплика на 60 % совпадает со словами собеседника в окне ±8 секунд, она выбрасывается.

## Замеры (сентябрь 2026)

| Что | Результат |
|---|---|
| Распознавание на компьютере | расхождение с лучшим облачным русским распознавателем 20%, как у Whisper large-v3 |
| От конца фразы до закрытия пункта | около 2,5 с в режиме с ключом |
| Сверка в облаке | 17 из 17 кейсов в трёх прогонах подряд, 0,6–1,5 с, 0,09 ₽ за запрос |
| Сверка на компьютере, видеокарта | 13 из 17 кейсов, 0,5–2 с |
| Сверка на компьютере, только процессор | 16 с – 7 мин на запрос, для живого разговора не годится |

## Если что-то не работает

В настройках есть «Сообщить о проблеме»: приложение копирует диагностику в буфер обмена и открывает форму на GitHub. В лог не пишутся ни текст разговора, ни ключи. Лог лежит в `%APPDATA%/SozvonQuest/logs`. При выходе новой версии на стартовом экране появится плашка со ссылкой.

Удалить приложение целиком: exe-файл, папку `%APPDATA%/SozvonQuest` (там же модели) и, если не нужны итоги созвонов, Документы → SozvonQuest.

## Запуск из исходников

```bash
npm install
cp .env.example .env     # или пройти мастер настройки внутри приложения
npm start
```

| Команда | Что делает |
|---|---|
| `npm start` | обычный запуск |
| `npm run start:mock` | без аудио: реплики печатаются руками, для отладки сверки и анимаций |
| `npm run build` | portable-exe в `dist/` через electron-builder |
| `npx electron . --demo --screenshot=outputs/demo.png` | live и финал с примером, три скриншота, выход |
| `npm run test:llm` | регресс сверки на живом API |
| `node test/test-tone.js` | замер распознавания на компьютере |
| `node test/test-score.js <папка сессии>` | пересчитать балл и разбор по сохранённой сессии |
